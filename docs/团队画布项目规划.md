## 总目标

把现有画布改造成团队内部在线系统，让成员可以通过网页访问，不再需要下载安装到本地。系统需要支持账户注册、团队子账号、项目共享、团队素材库、云端保存画布，以及后续自动部署到 GitHub 关联的线上环境。

| 静态资源 | 后端静态托管或 Cloudflare Pages | 承载现有 `static/` 前端页面 |

## 免费方案风险

- Render 免费服务空闲后会休眠，首次访问会慢。
- Supabase 免费数据库空间有限，适合先存账户、项目和画布，不适合直接存大量图片。
- Cloudflare R2 免费额度够小团队起步，但视频生成多了会较快占用空间。
- AI 模型调用费用不属于托管免费额度，需要由团队自己的 API Key 承担。
