更新时间：2026-07-24

## 当前状态

- 项目仓库：`yiyuqiao2748/yishu-canvas`
- 本地目录：`D:\codex code\yishu-canvas`
- 当前基础版本：已合并原作者 `hero8152/Infinite-Canvas` 最新上游版本 `2026.07.23`
- 当前定位：由本地单机画布，改造成小团队可在线使用的专属网页画布
- 团队规模：少于 10 人
- 预算目标：优先使用免费方案，后续按使用量再升级

## 总目标

把现有画布改造成团队内部在线系统，让成员可以通过网页访问，不再需要下载安装到本地。系统需要支持账户注册、团队子账号、项目共享、团队素材库、云端保存画布，以及后续自动部署到 GitHub 关联的线上环境。

## 推荐免费架构

| 模块 | 推荐服务 | 用途 |
| --- | --- | --- |
| 代码托管 | GitHub | 存放代码、版本管理、协作开发 |
| 自动部署 | GitHub Actions | 推送代码后自动发布 |
| 后端服务 | Render Free | 部署现有 FastAPI 后端 |
| 用户认证 | Supabase Auth | 注册、登录、团队成员身份 |
| 数据库 | Supabase Postgres | 保存用户、团队、项目、画布、权限 |
| 文件存储 | Cloudflare R2 Free | 保存图片、视频、素材、缩略图 |
| 静态资源 | 后端静态托管或 Cloudflare Pages | 承载现有 `static/` 前端页面 |

说明：GitHub Pages 只能托管静态页面，不能单独运行 FastAPI、数据库、登录系统和文件上传，所以不能只靠 GitHub Pages 完成团队在线版。

## 免费方案风险

- Render 免费服务空闲后会休眠，首次访问会慢。
- Supabase 免费数据库空间有限，适合先存账户、项目和画布，不适合直接存大量图片。
- Cloudflare R2 免费额度够小团队起步，但视频生成多了会较快占用空间。
- AI 模型调用费用不属于托管免费额度，需要由团队自己的 API Key 承担。
