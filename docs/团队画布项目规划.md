## 总目标

把现有画布改造成团队内部在线系统，让成员可以通过网页访问，不再需要下载安装到本地。系统需要支持账户注册、团队子账号、项目共享、团队素材库、云端保存画布，以及后续自动部署到 GitHub 关联的线上环境。

## 推荐免费架构

| 模块 | 推荐服务 | 用途 |
| --- | --- | --- |
| 代码托管 | GitHub | 存放代码、版本管理、协作开发 |
| 自动部署 | GitHub Actions | 推送代码后自动发布 |
| 后端服务 | Render Free | 部署现有 FastAPI 后端 |
| 用户认证 | Supabase Auth | 注册、登录、团队成员身份 |
| 数据库 | Supabase Postgres | 保存用户、团队、项目、画布、权限 |
| 文件存储 | Cloudflare R2 Free | 保存图片、视频、素材、缩略图 |
| 静态资源 | 后端静态托管或 Cloudflare Pages | 承载现有 `static/` 前端页面 |

## 核心功能规划

### 1. 账户系统

- 用户注册
- 用户登录
- 用户退出
- 登录状态保持
- 密码重置
- 邮箱验证
- 个人资料

### 2. 团队管理

- 创建团队
- 邀请成员
- 成员加入团队
- 成员角色管理
- 移除成员
- 团队基础设置

建议角色：

| 角色 | 权限 |
| --- | --- |
| Owner | 管理团队、成员、密钥、所有项目 |
| Admin | 管理成员和团队项目 |
| Member | 创建、查看、编辑授权项目 |

### 3. 项目共享

- 创建项目
- 项目列表
- 项目归属团队
- 项目成员权限
- 团队内共享项目
- 项目归档
- 项目删除和恢复

### 4. 云端画布

- 画布保存到数据库
- 画布自动保存
- 画布版本记录
- 画布恢复历史版本
- 团队成员可打开同一个项目画布
- 防止多人覆盖保存

### 5. 团队素材库

- 上传图片
- 上传视频
- 保存 AI 生成结果
- 素材归属团队
- 素材归属项目
- 素材分类
- 缩略图缓存
- 删除素材时检查引用关系

### 6. API 密钥管理

- 团队级 API Key 配置
- 后端加密保存密钥
- 普通成员不可直接查看密钥
- 记录模型调用日志
- 记录调用人、项目、模型、时间、状态
- 后续可扩展成本统计

### 7. 在线部署

- Docker 化 FastAPI 服务
- 配置生产环境变量
- GitHub Actions 自动部署
- Render 绑定 GitHub 仓库
- 配置 Supabase
- 配置 Cloudflare R2
- 绑定团队访问域名

### 8. 公司团队工作台体验

- 普通成员进入后直接到画布/工作台，不需要配置 API
- 管理员可配置团队 API、模型和密钥
- 团队 API Key 只保存在后端/数据库加密字段，前端不回显完整 Key
- 普通成员使用团队默认模型生成，不互相看到个人未共享画布
- 生成图片优先保存在自己的当前画布，需要共享时再保存到团队素材
- 团队素材作为共享资产库，才写入 R2/NAS
- 普通画布和智能画布的右侧资产库布局保持一致
- 整体视觉改为深色红金“AI 设计师 / 公司团队工作台”风格

## 免费方案风险

- Render 免费服务空闲后会休眠，首次访问会慢。
- Supabase 免费数据库空间有限，适合先存账户、项目和画布，不适合直接存大量图片。
- Cloudflare R2 免费额度够小团队起步，但视频生成多了会较快占用空间。
- AI 模型调用费用不属于托管免费额度，需要由团队自己的 API Key 承担。
